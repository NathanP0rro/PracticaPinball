## Controles

| Acción | Teclado | Arcade USB | Mando XInput |
|---|---|---|---|
| Lanzador | Flecha arriba | Button N | Face Button Bottom |
| Flipper izquierdo | Flecha izquierda | Button N | Left Shoulder |
| Flipper derecho | Flecha derecha | Button N | Right Shoulder |
| Reiniciar bola | R | Button N | Special Right |

## Valores físicos

**Bola:** escala 0,025 · masa 0,5 kg · Linear Damping 0,01 · Angular Damping 0,0 · CCD activado · Inertia Conditioning desactivado

**Material físico (`bolaphysicalmaterial`):** Friction 0,05 · Static Friction 0,0 · Restitution 0,75
